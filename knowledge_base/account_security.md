# Account Security and Compromise Protocols

## 1. Security Incident Classification
- **High Risk**: Unauthorized login attempts from unknown IP ranges, API key leaks on public repos, password compromise, suspicious bulk data downloads.
- **Action Required**: Immediate account lockdown, token revocation, forced password reset, and notification sent to security team.

## 2. Account Suspension & Unlocking Procedure
- Accounts locked due to security anomalies require **Human Security Officer Approval** before unlocking.
- Verification steps include identity confirmation via multi-factor recovery code or security questions.
