# AgentFlow Customer FAQ & General Documentation

## Q1: How do I change my account subscription plan?
Navigate to Billing Settings -> Subscription -> Change Plan. Changes take effect at the start of the next billing cycle.

## Q2: Can I invite team members to my workspace?
Yes. Team administrators can add members under Workspace Settings -> Team Members -> Invite. Assign roles such as Admin, Manager, or Viewer.

## Q3: Where can I find API documentation and API keys?
API documentation is available at `/docs` or `/redoc` when system is running. API keys can be generated in Developer Settings -> API Keys.

## Q4: How is customer data protected?
AgentFlow uses AES-256 encryption at rest and TLS 1.3 in transit. All AI processing adheres to enterprise privacy guidelines and data is never used to train third-party public models.
